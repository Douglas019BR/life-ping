# Histórias de Usuário - Life Ping

## Epic 1: Cadastro e Pagamento

### US001 - Visualizar Landing Page
**Como** visitante  
**Quero** visualizar informações sobre o serviço Life Ping  
**Para** entender como funciona e decidir se quero contratar

**Prioridade**: Alta  
**Estimativa**: 3 pontos

---

### US002 - Realizar Cadastro
**Como** cliente  
**Quero** preencher um formulário com meus dados pessoais  
**Para** criar minha conta no sistema

**Dados necessários**:
- Nome completo
- Número de WhatsApp
- 1 a 3 contatos de emergência (nome + WhatsApp)
- Mensagem personalizada de emergência (opcional)
- Horário preferido para verificação diária (padrão: 14:00)

**Prioridade**: Alta  
**Estimativa**: 5 pontos

---

### US003 - Realizar Pagamento
**Como** cliente  
**Quero** realizar o pagamento do serviço  
**Para** ativar minha conta e começar a usar o Life Ping

**Prioridade**: Alta  
**Estimativa**: 8 pontos

---

### US004 - Confirmar Cadastro
**Como** cliente  
**Quero** receber confirmação de que meu cadastro foi realizado com sucesso  
**Para** ter certeza de que o serviço está ativo

**Prioridade**: Média  
**Estimativa**: 2 pontos
